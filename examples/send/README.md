examples/send
=============

One short packet a minute on 868 MHz, inside the 1 % duty cycle, from an Active Object. TRANSMITS, and only after the top button is pressed: put an antenna or a 50 ohm load on the sub-GHz connector (J501) first. 868 MHz is a European band; check your country's rules before running it.

Docs: https://docs.kode.diy/modules/mesh
