examples/console_actions
========================

The module on kodeOS's console: 12 functions and 23 variables, from an Active Object. TRANSMITS only when asked from the console, after mesh_tx_arm is given 1: put an antenna or a 50 ohm load on the connector of the band in use first. Its test signal is refused unless the build sets CONFIG_MESH_LAB.

Docs: https://docs.kode.diy/modules/mesh
